# El Niño 2026–2027: análisis histórico, precipitaciones y pronóstico

**Universidad Nacional del Altiplano — Puno**  
**Maestría en Ciencia de Datos**  
**Curso:** Visualización de Datos

## Objetivo

Comunicar mediante visualizaciones interactivas una historia basada en datos reales sobre la evolución del fenómeno El Niño, sus antecedentes históricos, su relación con las precipitaciones en el Perú y su posible evolución futura.

## Estructura del proyecto

- **ML 1 — Similitud histórica:** comparación de las anomalías oceánicas de 2026 con episodios anteriores.
- **ML 2 — Precipitaciones del Perú:** análisis de datos de precipitación de NASA POWER y su relación con indicadores ENSO.
- **ML 3 — Pronóstico experimental:** estimación de la evolución del índice Niño 3.4 durante seis meses.

## Fuentes de datos

- NOAA Climate Prediction Center (CPC).
- NASA POWER.
