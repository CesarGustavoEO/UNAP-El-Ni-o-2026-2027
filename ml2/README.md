# ML 2 — El Niño y precipitaciones del Perú

Universidad Nacional del Altiplano · Maestría en Ciencia de Datos · Visualización de Datos.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicación en GitHub y Streamlit

1. Extraer el ZIP. Subir **el contenido de la carpeta**, no el ZIP, a un repositorio GitHub propio.
2. Confirmar que `app.py`, `requirements.txt` y `datos/` están en la raíz de ese repositorio individual.
3. En Streamlit Community Cloud seleccionar repositorio, rama `main` y archivo `app.py`.
4. Para el repositorio **grupal**, subir el mismo contenido dentro de `ml2/`, sin sobrescribir la aplicación principal.

## Evidencia reproducible

- `app.py`: dashboard editorial editable.
- `Exploracion_Colab.ipynb`: exploración en Google Colab.
- `09_ml2_peru_v3.py`: código de análisis.
- `datos/`: CSV reales NOAA CPC y NASA POWER y resultados procesados.
